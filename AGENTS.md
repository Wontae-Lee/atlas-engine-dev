# AGENTS.md — Atlas Engine

This file is a compact router. Read the linked document for the task before
changing code, and update that document when an intentional change makes it
stale.

## Stable rules

- Respond in Korean unless the user asks for another language.
- Do not run builds, tests, benchmarks, simulations, generators, or formatters
  unless the user explicitly asks.
- Preserve native TBB builds and nvcc CUDA builds. A native TBB build must not
  require the CUDA toolkit.
- Keep `include/atlas/` and `src/atlas/` as the computational core. Python and
  Interactive are independent consumers and never dependencies of the core.
- Preserve the Python PascalCase API and select the engine before native imports.
- Keep TBB and CUDA Docker runtime targets separate.
- New or changed code under `include/atlas/` and `src/atlas/` carries English
  Doxygen. Multi-line documentation uses `/** */`. Elsewhere, do not add
  comments unless the task asks for them.
- `include/atlas/atlas.h` is generated by `tools/generate_headers.py`; do not
  edit it by hand.
- Every module under `include/atlas/` has a matching document under
  `docs/atlas/<module>/`. Update it with intentional module changes. Update the
  architecture pipeline documents when ownership or phase ordering changes.
