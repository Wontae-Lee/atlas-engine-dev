# CLAUDE.md — Atlas Engine

This file is a **map**. It does not hold the full instructions; it points to the
documents that do. When contributing to Atlas Engine, read the relevant linked
document before changing code, and keep that document in sync when the change is
intentional.

The detailed material lives in two places:

- [`docs/guidelines/`](docs/guidelines/) — *how to work on it*: workflow, code
  style, build/test, and dependencies.
- [`docs/atlas/`](docs/atlas/) — *per-module documentation* for the refactored
  modules: their structure, the shared tagged-union leaf pattern, and how to
  extend each.

## Always Applies

A few rules are easy to miss; everything else is in the linked docs.

- Respond in Korean unless the user asks for another language.
- Do not run builds, tests, benchmarks, simulations, generators, or formatters
  unless the user explicitly asks.
- Do not write source-code comments unless explicitly requested; when
  requested, write them in English.
- `include/atlas/atlas.h` is generated by `tools/generate_headers.py` — do not
  hand-edit it.
- When you make an intentional change to a documented module, update its
  document under `docs/atlas/` in the same change.

### Understanding a module → `docs/atlas/`

These modules share the **tagged-union leaf** pattern: a concrete umbrella type
wraps one of several self-contained leaf types and dispatches to it. Trivially
copyable leaves use `DeviceVariant` (`include/atlas/core/device_variant.h`,
host+device, `DeviceBuffer<T>`-capable); leaves that own a `DeviceBuffer` use
`HostVariant` (`include/atlas/core/host_variant.h`, host-only, move-based).

| Module | Read |
|---|---|
| Codec — per-cell solver selection | [atlas/codec/codec.md](docs/atlas/codec/codec.md) |
| Collider — particle/boundary collision resolution | [atlas/collider/collider.md](docs/atlas/collider/collider.md) |
| Sink — particle removal (despawn) at a boundary | [atlas/sink/sink.md](docs/atlas/sink/sink.md) |
| Source — particle emission from a boundary | [atlas/source/source.md](docs/atlas/source/source.md) |
| Material — species properties + device-side table | [atlas/material/material.md](docs/atlas/material/material.md) |
