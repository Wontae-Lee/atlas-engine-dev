
# Quick Start

## Installation Prerequisites

The details of the installation process are on the [README.md](./doc/installation/README.md) file.

### 1. Update and upgrade the system

```shell
sudo apt-get update
sudo apt-get upgrade
```

### 2. Prerequisites

```shell
sudo apt-get install -y cmake build-essential libtbb-dev pkg-config libglew-dev mesa-common-dev libglu1-mesa-dev freeglut3-dev libglfw3-dev
```
